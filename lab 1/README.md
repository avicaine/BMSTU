## 1\. ЧАСТЬ 1. ИЗУЧЕНИЕ ОПЕРАТОРОВ ЯЗЫКА СИ++

### 1.1. Цель работы

Овладение навыками разработки программ на языке Си++, реализующих циклические алгоритмы с использованием различных разновидностей операторов циклов.

### 1.2. Условие задачи

Вычислить значение выражения:

$$\\sqrt{3+\\sqrt{6+\\ldots\\sqrt{60+\\sqrt{63}}}}$$

В работе необходимо представить реализацию трех видов цикла: с предусловием (`while`), с постусловием (`do ... while`) и `for`.

### 1.3. Текст программы с комментариями

Числа под знаками корня образуют последовательность 3, 6, 9, ..., 60, 63 (шаг 3, всего 21 число). Выражение считается «изнутри наружу»: сначала $\\sqrt{63}$, затем $\\sqrt{60+\\sqrt{63}}$ и так далее до $\\sqrt{3+\\ldots}$. Поэтому переменная `i` меняется от 63 до 3 с шагом −3, а в переменной `sum` накапливается значение вложенного корня. Число итераций (`count`) выводится для наглядности: оно показывает, сколько раз выполнилось тело цикла.

```cpp
//8 Вариант

#include <iostream>
#include <cmath> // Импортируем библиотеку cmath для нахождения квадратного корня
#include <iomanip> // Импортируем библиотеку iomanip для выставления количества знаков после запятой
#include <windows.h> // Импортируем библиотеку windows для работы с кодировкой консоли
using namespace std; // Не писать std::

int main() {
    SetConsoleOutputCP(65001); // Устанавливаем UTF-8 для вывода русских букв в консоли
    SetConsoleCP(65001); // Устанавливаем UTF-8 для ввода
    // Вычисляем sqrt(3 + sqrt(6 + ... sqrt(60 + sqrt(63)))) начиная с самого внутреннего корня
    double sum; // значение выражения
    int count; // число итераций цикла
    int i; // число под корнем (63, 60, ..., 3)

    sum = 0;
    count = 0;
    for (i = 63; i >= 3; i -= 3) { // цикл for
        count += 1;
        sum = sqrt(i + sum); // прибавляем число и берем корень
    }
    cout << setprecision(10) << fixed << "Цикл for: значение выражения = " << sum;
    cout << " " << "Количество итераций = " << count << endl;


    sum = 0;
    count = 0;
    i = 63;
    while (i >= 3) { // цикл с предусловием
        count += 1;
        sum = sqrt(i + sum); // прибавляем число и берем корень
        i -= 3; // следующее число меньше на 3
    }
    cout << "Цикл while: значение выражения = " << sum;
    cout << " " << "Количество итераций = " << count << endl;


    sum = 0;
    count = 0;
    i = 63;
    do { // цикл с постусловием
        count += 1;
        sum = sqrt(i + sum); // прибавляем число и берем корень
        i -= 3; // следующее число меньше на 3
    } while (i >= 3);
    cout << "Цикл do-while: значение выражения = " << sum;
    cout << " " << "Количество итераций = " << count << endl;

    return 0;
}
```

## 2\. ЧАСТЬ 2. ИЗУЧЕНИЕ МАССИВОВ И СТРУКТУР ЯЗЫКА СИ++

### 2.1. Цель работы

Овладение навыками разработки программ на языке Си++, использующих структурные типы данных (структуры, строки `string` и динамические массивы `vector`).

### 2.2. Условие задачи

Определить структуру «студент», поля структуры: ФИО, массив элементов структуры «дисциплина» (не менее 4-х элементов, результаты сдачи сессии). Структура «дисциплина» включает поля: название, оценка. Использовать шаблоны классов языка Си++: для строк — `string`, для массива переменных структурного типа — `vector` (число элементов задается переменной `n`, значение которой вводится с клавиатуры). Для ввода структурной переменной с клавиатуры и вывода ее на консоль использовать отдельные функции. После ввода исходных данных вывести все введенные данные для контроля ввода.

В программе задать группу студентов (массив переменных структурного типа) и выполнить действие: **определить, какой из предметов был сдан группой лучше всего.**

Определить недостаток подобного представления данных, если описываются результаты сдачи сессии одной группой, и предложить способы его устранения.

### 2.3. Текст программы с комментариями

Предмет считается сданным лучше всего, если по нему самый высокий средний балл группы. Для каждого предмета считаются сумма оценок и число студентов, сдававших этот предмет (функция `bestSubject`), затем вычисляется средний балл по каждому предмету и выбирается наибольший. Если лучших предметов несколько, выводятся все. Ввод и вывод данных одного студента вынесены в отдельные функции `inputStudent` и `printStudent`, ввод чисел и строк проверяется функциями `inputNumber` и `inputString`.

```cpp
//8 Вариант

#include <iostream>
#include <string> // По заданию, для работы со строками
#include <vector> // По заданию, для работы с динамическими массивами
#include <iomanip> // Для выставления количества знаков после запятой
#include <windows.h> // Для русских букв в консоли

using namespace std; // Не писать std::

struct Discipline {
    // Задаём структуру дисциплина по условию
    string name; // название предмета
    int grade; // оценка
};

struct Student {
    // Задаём структуру студент по условию
    string fullName; // ФИО
    vector<Discipline> subjects; // массив дисциплин студента (не меньше 4)
};

// Ввод целого числа с проверкой: если ввели не число (например, букву), просим ввести заново
int inputNumber() {
    int x;
    while (!(cin >> x)) {
        cout << "Это не число. Введите заново: ";
        cin.clear(); // сбрасываем ошибку ввода
        cin.ignore(1000, '\\n'); // выбрасываем неверный ввод
    }
    cin.ignore(1000, '\\n'); // убираем \\n, чтобы следующий getline считался нормально
    return x;
}

// Ввод строки, которая не должна быть пустой
string inputString() {
    string s;
    getline(cin, s);
    while (s.empty()) {
        cout << "Строка не должна быть пустой. Повторите ввод: ";
        getline(cin, s);
    }
    return s;
}

// Проверка: есть ли среди первых count предметов студента предмет с названием name
bool hasSubject(const Student\& s, int count, string name) {
    for (int i = 0; i < count; i++) {
        if (s.subjects\[i].name == name) {
            return true; // нашли такой же предмет
        }
    }
    return false; // такого предмета еще нет
}

// Ввод данных одного студента (знак \& нужен, чтобы функция меняла самого студента, а не его копию)
void inputStudent(Student\& s) {
    cout << "Введите ФИО студента: ";
    s.fullName = inputString();

    cout << "Введите количество дисциплин (не меньше 4): ";
    int k = inputNumber(); // количество дисциплин
    while (k < 4) {
        cout << "Должно быть не меньше 4. Повторите ввод: ";
        k = inputNumber();
    }
    s.subjects.resize(k); // делаем размер вектора равным количеству дисциплин

    for (int i = 0; i < k; i++) {
        cout << "Предмет №" << i + 1 << endl;
        cout << "Введите название предмета: ";
        s.subjects\[i].name = inputString();
        // один и тот же предмет у студента дважды быть не может, проверяем уже введенные (0...i-1)
        while (hasSubject(s, i, s.subjects\[i].name)) {
            cout << "Такой предмет уже есть. Повторите ввод: ";
            s.subjects\[i].name = inputString();
        }

        cout << "Введите оценку (от 2 до 5): ";
        s.subjects\[i].grade = inputNumber();
        while (s.subjects\[i].grade < 2 || s.subjects\[i].grade > 5) {
            cout << "Оценка может быть только от 2 до 5. Введите заново: ";
            s.subjects\[i].grade = inputNumber();
        }
    }
}

// Вывод данных одного студента (const - функция только выводит, ничего не меняет)
void printStudent(const Student\& s) {
    cout << "Студент: " << s.fullName << endl;
    for (int i = 0; i < s.subjects.size(); i++) {
        cout << "  " << s.subjects\[i].name << ": " << s.subjects\[i].grade << endl;
    }
}

// Задание 8: определить, какой предмет сдан группой лучше всего
// (лучше всего = самый высокий средний балл по предмету)
void bestSubject(const vector<Student>\& group) {
    vector<string> names; // названия всех предметов группы (каждое один раз)
    vector<int> sums; // сумма оценок по каждому предмету
    vector<int> counts; // сколько студентов сдавали каждый предмет

    // Проходим по всем оценкам всех студентов
    for (int i = 0; i < group.size(); i++) {
        for (int j = 0; j < group\[i].subjects.size(); j++) {
            // Ищем этот предмет в списке names
            int k = -1; // номер предмета в списке (-1 значит "не нашли")
            for (int t = 0; t < names.size(); t++) {
                if (names\[t] == group\[i].subjects\[j].name) {
                    k = t;
                }
            }
            // Если такого предмета еще нет, добавляем его в конец списков
            if (k == -1) {
                names.push\_back(group\[i].subjects\[j].name);
                sums.push\_back(0);
                counts.push\_back(0);
                k = names.size() - 1;
            }
            sums\[k] += group\[i].subjects\[j].grade; // прибавляем оценку к сумме
            counts\[k] += 1; // еще один студент сдавал этот предмет
        }
    }

    // Считаем средний балл по каждому предмету и находим наибольший
    vector<double> avg(names.size()); // средний балл по каждому предмету
    double best = 0; // наибольший средний балл
    cout << "Средний балл группы по предметам:" << endl;
    for (int k = 0; k < names.size(); k++) {
        avg\[k] = (double)sums\[k] / counts\[k]; // (double) нужен, чтобы деление было не целочисленным
        cout << names\[k] << ": " << avg\[k] << endl;
        if (avg\[k] > best) {
            best = avg\[k];
        }
    }

    // Выводим все предметы с наибольшим средним баллом (их может быть несколько)
    cout << "Лучше всего группа сдала: ";
    for (int k = 0; k < names.size(); k++) {
        if (avg\[k] == best) {
            cout << names\[k] << " ";
        }
    }
    cout << "(средний балл " << best << ")" << endl;
}

int main() {
    SetConsoleOutputCP(65001); // Устанавливаем UTF-8 для вывода русских букв в консоли
    SetConsoleCP(65001); // Устанавливаем UTF-8 для ввода
    cout << setprecision(2) << fixed; // дробные числа выводим с двумя знаками после запятой

    cout << "Введите количество студентов: ";
    int n = inputNumber(); // количество студентов в группе
    while (n <= 0) {
        cout << "Должно быть больше 0. Повторите ввод: ";
        n = inputNumber();
    }

    vector<Student> group(n); // группа студентов (вектор из n студентов)

    // Ввод данных
    for (int i = 0; i < n; i++) {
        cout << endl << "Студент №" << i + 1 << endl;
        inputStudent(group\[i]);
    }

    // Вывод всех введенных данных для контроля ввода
    cout << endl << "Введенные данные:" << endl;
    for (int i = 0; i < n; i++) {
        printStudent(group\[i]);
    }

    // Решение задания 8
    cout << endl;
    bestSubject(group);

    return 0;
}
```

### 2.5. Тренировочная часть: размер структуры в памяти

Дана структура `Test`. Если вывести ее размер, то будет напечатано 12. Нужно разобраться, почему так, и переписать структуру так, чтобы она занимала 8 байт.

```cpp
#include <iostream>
using namespace std;

struct Test {
    short b;       // 2 байта
    int a;         // 4 байта
    char ch1, ch2; // 1 + 1 байт
};

struct TestNew {
    int a;         // 4 байта
    short b;       // 2 байта
    char ch1, ch2; // 1 + 1 байт
};

int main() {
    cout << "sizeof(Test) = " << sizeof(Test) << endl;
    cout << "sizeof(TestNew) = " << sizeof(TestNew) << endl;
    return 0;
}
```

Результат работы программы:

```text
sizeof(Test) = 12
sizeof(TestNew) = 8
```

**Почему 12 байт.** Компилятор выравнивает поля: каждое поле лежит по адресу, кратному его размеру, а размер всей структуры кратен размеру самого большого поля (здесь 4 байта для `int`). В структуре `Test`:

* `short b` занимает 2 байта (адреса 0–1);
* после него 2 байта пустого места, чтобы `int a` лежал по адресу, кратному 4;
* `int a` занимает 4 байта (адреса 4–7);
* `char ch1, ch2` занимают 2 байта (адреса 8–9);
* в конце 2 байта пустого места, чтобы размер структуры был кратен 4.

Итого: 2 + 2 + 4 + 2 + 2 = 12 байт.

**Как уменьшить до 8 байт.** Нужно расположить поля от самого большого к самому маленькому: `int a`, `short b`, `char ch1, ch2`. Тогда пустого места нет: 4 + 2 + 1 + 1 = 8 байт (структура `TestNew`).

### 2.6. Недостаток представления данных и способы его устранения

**Недостаток.** В заданной структуре название предмета хранится внутри каждой оценки каждого студента. Если сессию сдает вся группа, названия одних и тех же предметов повторяются у каждого студента. Из-за этого:

* расходуется лишняя память;
* название одного предмета можно записать по-разному («Математика», «математика», «Матан»), и программа посчитает их разными предметами;
* чтобы сравнить предметы между студентами (например, найти лучший предмет), приходится искать совпадения по строкам, как это сделано в функции `bestSubject`.

**Способы устранения.**

1. Хранить один общий список предметов группы (`vector<string>`), а у каждого студента хранить только оценки, в том же порядке, что и предметы в списке.
2. Присвоить каждому предмету числовой код (номер) и хранить в оценке код предмета вместо названия.
3. Хранить оценки всей группы одной таблицей «студент × предмет» (двумерный массив), а названия предметов и ФИО — в отдельных списках.
