## Сборка и запуск

Нужен компилятор `g++` с поддержкой C++17.

**Лабораторная 2**

```bash
cd "lab 2"
g++ -std=c++17 -Wall -Wextra -o lab2 main.cpp
./lab2 write text goods.txt < examples/input.txt   # запись в текстовый файл
./lab2 read  text goods.txt                        # чтение
```

Режимы: `write` или `read`, затем `text` или `binary`, затем имя файла.

**Лабораторная 3**

```bash
cd "lab 3/part1_vector"
g++ -std=c++17 -Wall -Wextra -o lab3_part1 main.cpp vector.cpp
./lab3_part1                                       # читает input.txt, пишет output.txt

cd ..
g++ -std=c++17 -Wall -Wextra -o lab3_part2 part2_inheritance.cpp
./lab3_part2
```
