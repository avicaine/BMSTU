## 1. ЧАСТЬ 1. КЛАССЫ И ПЕРЕГРУЗКА ОПЕРАЦИЙ В ЯЗЫКЕ СИ++

### 1.1. Цель работы

Овладение навыками разработки программ на языке Си++, использующих классы и перегрузку стандартных операций.

### 1.2. Условие задачи

Дан класс `Vector`, задающий вектор размерности $n$. Поля класса: указатель на динамический массив, задающий вектор (тип элемента `double`), и число элементов (`int`). Класс включает конструктор без параметров (пустой вектор, число элементов равно 0), конструктор на основе обычного одномерного массива, конструктор копирования, конструктор перемещения и деструктор.

Необходимо перегрузить операции и продемонстрировать их работу: `[]` (обращение к элементу по индексу), `=` (присваивание с копированием), `=` (присваивание с перемещением), `<<` (вставка в поток `cout` или в файл) и `>>` (извлечение из потока `cin` или из файла). Также нужно показать разницу между конструктором копирования и конструктором перемещения и между присваиванием с копированием и перемещением. Код класса разместить в двух файлах: заголовочном файле класса и файле реализации.

**Индивидуальная операция варианта 8:** `*` — умножение вектора на число. На выходе вектор такой же размерности, каждый элемент которого равен произведению соответствующего элемента исходного вектора на число.

|Элемент вектора|Первый операнд|Второй операнд|Результат|
|-|-|-|-|
|`double`|`Vector`|`double`|`Vector`|

Все входные данные читаются из файла `input.txt`, результаты выводятся в файл `output.txt`.

### 1.3. Текст программы с комментариями

Класс `Vector` хранит указатель `p` на динамический массив из `double` и число элементов `n`. Описание класса вынесено в заголовочный файл `vector.h`, реализация функций — в `vector.cpp`, демонстрация работы — в `main.cpp`. Массив создается оператором `new[]` и освобождается в деструкторе. Во всех конструкторах, деструкторе и операциях присваивания на консоль выводится сообщение, чтобы было видно, какая функция вызывалась. Значения векторов выводятся в файл `output.txt`. Для результата операции `*` используется закрытый вспомогательный конструктор `Vector(int n)`: он выделяет память под $n$ элементов без инициализации.

**Файл `vector.h`:**

```cpp
// vector.h - заголовочный файл класса Vector.
// Лабораторная работа №3, часть 1, вариант 8.
// Индивидуальная операция: * (умножение вектора на число), тип элементов - double.
#ifndef VECTOR_H
#define VECTOR_H

#include <iostream>

class Vector // Класс-вектор: динамический массив из double
{
    double *p = nullptr; // Указатель на динамический массив, задающий вектор
    int n = 0;           // Число элементов (размерность) вектора

    // Закрытый вспомогательный конструктор: выделяет память под n элементов
    // без инициализации. Нужен только операции *, чтобы создать вектор-результат.
    explicit Vector(int n);

public:
    Vector();                            // Конструктор без параметров: пустой вектор (n = 0)
    Vector(const double *arr, int size); // Конструктор на основе обычного массива
    Vector(const Vector &V);             // Конструктор копирования
    Vector(Vector &&V) noexcept;         // Конструктор перемещения
    ~Vector();                           // Деструктор

    double &operator[](int index);               // Операция []: обращение к элементу
    Vector &operator=(const Vector &v2);         // Операция =: присваивание с копированием
    Vector &operator=(Vector &&v2) noexcept;     // Операция =: присваивание с перемещением

    // Индивидуальная операция варианта 8: вектор * число.
    // Первый операнд - объект класса, поэтому операция - функция класса
    // с одним параметром (второй операнд). Объект не меняется (const).
    Vector operator*(double x) const;

    // << и >> не могут быть функциями класса (первый операнд - поток),
    // поэтому они определены вне класса и объявлены дружественными
    friend std::ostream &operator<<(std::ostream &os, const Vector &V);
    friend std::istream &operator>>(std::istream &is, Vector &V);
};

#endif // VECTOR_H
```

**Файл `vector.cpp`:**

```cpp
// vector.cpp - реализация класса Vector.
// Лабораторная работа №3, часть 1, вариант 8.
#include "vector.h"
#include <utility> // std::swap

using namespace std;

// Закрытый конструктор: память выделяется, элементы не инициализируются
Vector::Vector(int n) : n(n)
{
    p = new double[n];
    cout << "Vector(int n)" << endl;
}

// Конструктор без параметров: поля уже равны nullptr и 0 (см. vector.h)
Vector::Vector()
{
    cout << "Vector()" << endl;
}

// Конструктор на основе обычного массива: копируем элементы в свою память
Vector::Vector(const double *arr, int size) : n(size)
{
    p = new double[n];
    for (int i = 0; i < n; i++) p[i] = arr[i];
    cout << "Vector(const double *arr, int size)" << endl;
}

// Конструктор копирования: создаем свой массив и копируем в него элементы,
// исходный вектор не меняется
Vector::Vector(const Vector &V) : n(V.n)
{
    p = new double[n];
    for (int i = 0; i < n; i++) p[i] = V.p[i];
    cout << "Vector(const Vector & V) n=" << n << endl;
}

// Конструктор перемещения: поля нового объекта пустые (nullptr, 0),
// после обмена с V новый объект владеет массивом, а V становится пустым
Vector::Vector(Vector &&V) noexcept
{
    swap(p, V.p);
    swap(n, V.n);
    cout << "Vector(Vector&& V)" << endl;
}

// Деструктор: освобождаем память
Vector::~Vector()
{
    cout << "~Vector() n=" << n << endl;
    if (p != nullptr) delete[] p;
}

// Операция []: возвращаем ссылку, чтобы элемент можно было и читать, и менять
double &Vector::operator[](int index)
{
    return p[index];
}

// Присваивание с копированием
Vector &Vector::operator=(const Vector &v2)
{
    if (this != &v2) // защита от присваивания вектора самому себе
    {
        if (p != nullptr) delete[] p; // освобождаем старую память
        n = v2.n;
        p = new double[n];
        for (int i = 0; i < n; i++) p[i] = v2.p[i];
    }
    cout << "Vector & operator =(const Vector& v2)" << endl;
    return *this;
}

// Присваивание с перемещением: забираем массив у v2, v2 становится пустым
// (подробная форма: после присваивания v2 пуст в любом случае)
Vector &Vector::operator=(Vector &&v2) noexcept
{
    if (this != &v2)
    {
        if (p != nullptr) delete[] p; // освобождаем старую память
        p = v2.p;                     // забираем массив
        n = v2.n;
        v2.p = nullptr;               // v2 больше не владеет массивом
        v2.n = 0;
    }
    cout << "Vector & operator =(Vector&& v2)" << endl;
    return *this;
}

// Индивидуальная операция: вектор * число.
// Результат - новый вектор той же размерности, исходный не меняется.
Vector Vector::operator*(double x) const
{
    Vector R(n); // вектор-результат, память выделена
    for (int i = 0; i < n; i++) R.p[i] = p[i] * x;
    return R;
}

// Вставка вектора в поток (cout или файл): "n=3: 1 2 3"
ostream &operator<<(ostream &os, const Vector &V)
{
    os << "n=" << V.n << ":";
    for (int i = 0; i < V.n; i++) os << " " << V.p[i];
    return os;
}

// Извлечение вектора из потока: сначала число элементов, затем сами элементы
istream &operator>>(istream &is, Vector &V)
{
    int k;
    is >> k;
    if (!is || k < 0) // неверные данные: помечаем поток как неисправный
    {
        is.setstate(ios::failbit);
        return is;
    }
    if (V.p != nullptr) delete[] V.p; // освобождаем память старого вектора
    V.n = k;
    V.p = new double[k];
    for (int i = 0; i < k; i++) is >> V.p[i];
    return is;
}
```

**Файл `main.cpp`:**

```cpp
// main.cpp - демонстрация работы класса Vector.
// Лабораторная работа №3, часть 1, вариант 8 (операция: вектор * число).
// Все входные данные читаются из input.txt, результаты выводятся в output.txt.
// Сообщения конструкторов, операций и деструкторов выводятся на консоль.
#include <iostream>
#include <fstream>
#include <vector>
#include <utility> // std::move
#include "vector.h"

using namespace std;

int main()
{
    ifstream fin("input.txt");   // Входной файл
    ofstream fout("output.txt"); // Выходной файл
    if (!fin || !fout)
    {
        cerr << "Error: can't open input.txt or output.txt" << endl;
        return 1;
    }

    // ---------- Создание векторов ----------
    Vector V0;                    // Конструктор без параметров: пустой вектор
    fout << "V0 = " << V0 << endl;

    Vector V1;                    // Пустой вектор, в него читаем данные из файла
    fin >> V1;                    // Операция >>: число элементов, затем элементы
    fout << "V1 = " << V1 << endl;

    int k;                        // Число элементов обычного массива
    fin >> k;
    vector<double> m(k);          // Обычный массив из файла
    for (int i = 0; i < k; i++) fin >> m[i];
    double x;                     // Число, на которое умножаем
    fin >> x;
    if (!fin)
    {
        cerr << "Error: wrong data in input.txt" << endl;
        return 2;
    }
    Vector V2(m.data(), k);       // Конструктор на основе обычного массива
    fout << "V2 = " << V2 << endl;
    fout << "x  = " << x << endl;

    // ---------- Операция [] ----------
    double old = V1[0];           // Чтение элемента
    fout << "V1[0] = " << old << endl;
    V1[0] = 7;                    // Запись элемента (слева от =)
    fout << "V1 after V1[0]=7: " << V1 << endl;
    V1[0] = old;                  // Возвращаем прежнее значение

    // ---------- Индивидуальная операция: вектор * число ----------
    Vector V3 = V1 * x;           // Результат - новый вектор
    fout << "V3 = V1 * x: " << V3 << endl;
    fout << "V1 unchanged: " << V1 << endl;
    Vector V4 = V2 * x;
    fout << "V4 = V2 * x: " << V4 << endl;

    // ---------- Конструктор копирования и перемещения ----------
    Vector C1(V1);                // Копирование: V1 не меняется
    fout << "copy ctor: V1 = " << V1 << endl;
    fout << "           C1 = " << C1 << endl;
    Vector C2(move(V1));          // Перемещение: V1 становится пустым
    fout << "move ctor: V1 = " << V1 << endl;
    fout << "           C2 = " << C2 << endl;

    // ---------- Присваивание с копированием и перемещением ----------
    Vector A1;                    // Пустой вектор для присваивания с копированием
    A1 = V3;                      // V3 не меняется
    fout << "copy =:    V3 = " << V3 << endl;
    fout << "           A1 = " << A1 << endl;
    Vector A2;                    // Пустой вектор для присваивания с перемещением
    A2 = move(V3);                // V3 становится пустым
    fout << "move =:    V3 = " << V3 << endl;
    fout << "           A2 = " << A2 << endl;

    return 0;
}
```

**Обоснование способа перегрузки операций:**

* `[]` и `=` по правилам языка обязательно должны быть функциями класса. Операция `[]` возвращает `double&`, чтобы элемент можно было и читать, и менять.
* `*` (вектор на число): первый операнд — объект класса, поэтому операция сделана функцией класса с одним параметром (числом). Она объявлена `const`, потому что исходный вектор не изменяется. Если бы первым операндом было число (`число * вектор`), функцию пришлось бы определять вне класса, так как у числа нет методов.
* `<<` и `>>` не могут быть функциями класса: первый операнд у них не `Vector`, а поток (`ostream` или `istream`). Они определены вне класса и объявлены дружественными (`friend`), чтобы иметь доступ к закрытым полям `p` и `n`. Благодаря параметрам-потокам они работают и с `cout`/`cin`, и с файлами.

**Копирование и перемещение.** Конструктор копирования и присваивание с копированием создают новый массив и копируют в него элементы, исходный вектор остается без изменений. Конструктор перемещения и присваивание с перемещением не копируют элементы, а забирают массив у исходного вектора, и исходный вектор становится пустым (`n = 0`). В присваивании с перемещением использована подробная форма (старая память освобождается, указатель забирается, у исходного вектора указатель обнуляется), поэтому исходный вектор пуст в любом случае.

### 1.4. Контрольный пример и результаты работы программы

**Входные данные (`input.txt`):**

```text
4

3
10 20 30.5
2.5
```

Первые две строки — вектор для операции `>>` (число элементов и элементы), следующие две — обычный массив для конструктора (число элементов и элементы), последняя строка — число $x$, на которое умножаются векторы.

**Ручной расчет (число $x = 2.5$):**

Вектор $V_1 = (1.5;\ 2;\ -3;\ 4.25)$:

|Элемент|Исходное значение|Умножение|Результат|

|`V1[0]`|1.5|$1.5 \cdot 2.5$|3.75|
|`V1[1]`|2|$2 \cdot 2.5$|5|
|`V1[2]`|−3|$-3 \cdot 2.5$|−7.5|
|`V1[3]`|4.25|$4.25 \cdot 2.5$|10.625|

Вектор $V_2 = (10;\ 20;\ 30.5)$:

|Элемент|Исходное значение|Умножение|Результат|
|-|-:|-|-:|
|`V2[0]`|10|$10 \cdot 2.5$|25|
|`V2[1]`|20|$20 \cdot 2.5$|50|
|`V2[2]`|30.5|$30.5 \cdot 2.5$|76.25|

## 2. ЧАСТЬ 2. НАСЛЕДОВАНИЕ КЛАССОВ В ЯЗЫКЕ СИ++

### 2.1. Цель работы

Овладение навыками разработки программ на языке Си++, использующих возможности наследования классов.

### 2.2. Условие задачи

Создать базовый класс «вектор на плоскости». Элементы класса: поля, задающие координаты точки (статус доступа `protected`), определяющей конец вектора (начало вектора находится в точке с координатами 0, 0); конструктор для инициализации полей; функция для печати координат вектора.

Создать производный класс «вектор в трехмерном пространстве». Элементы класса: дополнительное поле, задающее дополнительную координату; конструктор для инициализации полей; переопределенная функция для печати координат вектора (внутри переопределенной функции должна вызываться функция из базового класса).

### 2.3. Текст программы с комментариями

Конструктор производного класса явно вызывает конструктор базового (`vec3(...) : vec2(x, y)`), а переопределенная функция `print` сначала вызывает функцию базового класса `vec2::print()`, затем печатает третью координату. Для двух вариантов полиморфизма сделано две пары классов:

* `vec2` и `vec3` — функции без `virtual` (статическое связывание): через указатель на `vec2`, настроенный на объект `vec3`, вызывается функция базового класса, поэтому координата `z` не печатается;
* `vec2v` и `vec3v` — функция `print` с `virtual` в базовом классе (динамическое связывание): вызывается функция того класса, к которому относится объект. С этими классами создан вектор указателей. В базовом классе добавлен виртуальный деструктор, чтобы объекты производного класса корректно удалялись через указатель на базовый класс.

Функция `print` не переводит строку, чтобы производный класс мог дописать третью координату в ту же строку, поэтому `endl` выводится в `main`.

```cpp
// Лабораторная работа №3, часть 2, вариант 8.
// Базовый класс «вектор на плоскости», производный класс
// «вектор в трехмерном пространстве». Два варианта переопределения функций:
//  1) статический полиморфизм (vec2, vec3) - функции без virtual,
//     вызываемая функция выбирается по типу указателя;
//  2) динамический полиморфизм (vec2v, vec3v) - функция print с virtual
//     в базовом классе, вызываемая функция выбирается по типу объекта.
#include <iostream>
#include <vector>
using namespace std;

// ---------- 1. Статический полиморфизм ----------
class vec2 // Базовый класс - «вектор на плоскости»
{
protected:
    double x, y; // Координаты конца вектора (начало - точка (0, 0))
public:
    vec2(double x, double y) // Конструктор для инициализации полей
    {
        this->x = x;
        this->y = y;
    }
    void print() // Печать координат (без перевода строки)
    {
        cout << "x=" << x << " y=" << y;
    }
};

class vec3 : public vec2 // Производный класс - «вектор в трехмерном пространстве»
{
    double z; // Дополнительная координата
public:
    vec3(double x, double y, double z) : vec2(x, y) // Явный вызов конструктора базового класса
    {
        this->z = z;
    }
    void print() // Переопределенная функция печати
    {
        vec2::print();       // Сначала функция из базового класса
        cout << " z=" << z;  // Затем дополнительная координата
    }
};

// ---------- 2. Динамический полиморфизм ----------
class vec2v // Базовый класс - «вектор на плоскости»
{
protected:
    double x, y;
public:
    vec2v(double x, double y)
    {
        this->x = x;
        this->y = y;
    }
    virtual ~vec2v() {} // Виртуальный деструктор (нужен при удалении через указатель на базовый класс)
    virtual void print() // Виртуальная функция печати
    {
        cout << "x=" << x << " y=" << y;
    }
};

class vec3v : public vec2v // Производный класс - «вектор в трехмерном пространстве»
{
    double z;
public:
    vec3v(double x, double y, double z) : vec2v(x, y)
    {
        this->z = z;
    }
    void print() // Переопределяет виртуальную функцию базового класса
    {
        vec2v::print();
        cout << " z=" << z;
    }
};

int main()
{
    cout << "1. Static polymorphism (no virtual)" << endl;
    vec2 a(3, 4);           // Объект базового класса
    vec3 b(1, 2, 3);        // Объект производного класса
    cout << "a.print():   "; a.print(); cout << endl; // Вызов через объект
    cout << "b.print():   "; b.print(); cout << endl; // Вызов через объект
    vec2 *p = &a;           // Указатель на базовый класс
    cout << "p->print():  "; p->print(); cout << endl; // Метод класса vec2
    p = &b;                 // Указатель на объект производного класса (преобразование допустимо)
    cout << "p->print():  "; p->print(); cout << "  <- z is not printed: function chosen by pointer type" << endl;
    cout << endl;

    cout << "2. Dynamic polymorphism (virtual)" << endl;
    vec2v av(3, 4);
    vec3v bv(1, 2, 3);
    vec2v *pv = &av;
    cout << "pv->print(): "; pv->print(); cout << endl; // Метод класса vec2v
    pv = &bv;
    cout << "pv->print(): "; pv->print(); cout << "  <- z is printed: function chosen by object type" << endl;
    cout << endl;

    cout << "3. Vector of pointers to objects of base and derived classes" << endl;
    vec2v  r1(3, 4), r2(-5, 12);        // Объекты базового класса
    vec3v  s1(1, 2, 3), s2(2, -1, 0.5); // Объекты производного класса
    vector<vec2v *> v;                  // Вектор указателей на объекты базового класса
    v.push_back(&r1);                   // В одном векторе указатели
    v.push_back(&s1);                   // на объекты базового
    v.push_back(&r2);                   // и производного
    v.push_back(&s2);                   // классов
    for (size_t i = 0; i < v.size(); i++)
    {
        cout << i + 1 << ") ";
        v[i]->print(); // Динамический полиморфизм: вызывается функция того класса, к которому относится объект
        cout << endl;
    }
    return 0;
}
```

### 2.4. Контрольный пример и результаты работы программы

**Контрольный пример (ожидаемый результат, определенный вручную):**

|Вызов|Что должно напечататься|Почему|
|-|-|-|
|`a.print()`|`x=3 y=4`|объект базового класса|
|`b.print()`|`x=1 y=2 z=3`|переопределенная функция: сначала `vec2::print()`, затем `z`|
|`p->print()`, `p` указывает на `a`|`x=3 y=4`|объект базового класса|
|`p->print()`, `p` указывает на `b`|`x=1 y=2`|без `virtual` функция выбирается по типу указателя (`vec2`), `z` не печатается|
|`pv->print()`, `pv` указывает на `av`|`x=3 y=4`|объект базового класса|
|`pv->print()`, `pv` указывает на `bv`|`x=1 y=2 z=3`|с `virtual` функция выбирается по типу объекта (`vec3v`)|

Вектор указателей содержит объекты `(3; 4)`, `(1; 2; 3)`, `(-5; 12)`, `(2; -1; 0.5)` в порядке добавления, поэтому должны быть напечатаны четыре строки с этими значениями.

**Результат работы программы:**

```text
1. Static polymorphism (no virtual)
a.print():   x=3 y=4
b.print():   x=1 y=2 z=3
p->print():  x=3 y=4
p->print():  x=1 y=2  <- z is not printed: function chosen by pointer type

2. Dynamic polymorphism (virtual)
pv->print(): x=3 y=4
pv->print(): x=1 y=2 z=3  <- z is printed: function chosen by object type

3. Vector of pointers to objects of base and derived classes
1) x=3 y=4
2) x=1 y=2 z=3
3) x=-5 y=12
4) x=2 y=-1 z=0.5
```

Результат совпадает с ожидаемым: при статическом связывании для объекта `b` через указатель `p` напечатаны только `x` и `y`, при динамическом — все три координаты; все четыре объекта вектора напечатаны своими функциями.

**Вывод по части 2:**
Реализованы базовый класс «вектор на плоскости» и производный класс «вектор в трехмерном пространстве». При статическом связывании (без `virtual`) функция выбирается по типу указателя, при динамическом (с `virtual`) — по типу объекта, на который он указывает. Динамическое связывание позволило обработать в одном цикле объекты разных классов через вектор указателей на базовый класс.
