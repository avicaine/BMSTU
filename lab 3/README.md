## Часть 1. Классы и перегрузка операций

**Условие.** Дан класс `Vector`, задающий вектор размерности n. Поля класса: указатель на динамический массив (тип элемента `double`) и число элементов (`int`). Класс включает конструктор без параметров (пустой вектор), конструктор на основе обычного массива, конструктор копирования, конструктор перемещения и деструктор. Нужно перегрузить операции `[]`, `=` (с копированием и с перемещением), `<<`, `>>`, а также индивидуальную операцию варианта 8: **`*` — умножение вектора на число**. Результат — вектор той же размерности, каждый элемент которого равен произведению соответствующего элемента исходного вектора на число (типы операндов: `Vector`, `double`; результат: `Vector`). Показать разницу между конструктором копирования и перемещения и между присваиванием с копированием и перемещением. Код класса разместить в заголовочном файле и файле реализации. Входные данные читать из `input.txt`, результаты выводить в `output.txt`.

**Решение.** Класс описан в [vector.h](part1_vector/vector.h), реализован в [vector.cpp](part1_vector/vector.cpp), демонстрация в [main.cpp](part1_vector/main.cpp).

- Массив создается оператором `new[]` и освобождается в деструкторе.
- Во всех конструкторах, деструкторе и операциях присваивания на консоль выводится сообщение, поэтому видно, какая функция вызывалась.
- Результаты (значения векторов) выводятся в файл `output.txt`, а сообщения идут на консоль (в `console.txt` они сохранены перенаправлением вывода `./lab3_part1 > console.txt`).
- Для создания результата операции `*` в классе есть закрытый вспомогательный конструктор `Vector(int n)`: он выделяет память под n элементов без инициализации. Он закрытый, потому что нужен только внутри класса.
- Конструктор перемещения и присваивание с перемещением забирают массив у исходного вектора и оставляют его пустым.

**Обоснование способа перегрузки операций:**

- `[]` и `=` по правилам языка должны быть функциями класса. Операция `[]` возвращает `double&`, чтобы элемент можно было и читать, и менять.
- `*` (вектор на число): первый операнд — объект класса, поэтому операция сделана функцией класса с одним параметром (числом). Она объявлена `const`, потому что исходный вектор не изменяется. Если бы первым операндом было число (вариант 9, `число * вектор`), функцию пришлось бы определять вне класса, так как у числа нет методов.
- `<<` и `>>` не могут быть функциями класса: первый операнд у них не `Vector`, а поток (`ostream` или `istream`). Они определены вне класса и объявлены дружественными (`friend`), чтобы иметь доступ к закрытым полям `p` и `n`. Благодаря параметрам-потокам они работают и с `cout`/`cin`, и с файлами.

**Разница между копированием и перемещением.** Конструктор копирования и присваивание с копированием создают новый массив и копируют в него элементы, исходный вектор остается без изменений. Конструктор перемещения и присваивание с перемещением не копируют элементы, а забирают массив у исходного вектора, и исходный вектор становится пустым (`n=0`). Это видно в `output.txt` (строки `copy` и `move`) и в сообщениях на консоли.

**Входной файл input.txt** (вектор для операции `>>`; число элементов и элементы обычного массива для конструктора; число для умножения):

**Ручной расчет.** Число x = 2,5. Вектор V1 = (1,5; 2; −3; 4,25), тогда V1 · x = (1,5·2,5; 2·2,5; −3·2,5; 4,25·2,5) = (3,75; 5; −7,5; 10,625). Вектор V2 = (10; 20; 30,5), тогда V2 · x = (25; 50; 76,25). Это совпадает с результатом программы (`V3` и `V4` в `output.txt`), а исходные векторы после умножения не изменились.

## Часть 2. Наследование классов

**Условие.** Создать базовый класс «вектор на плоскости»: поля — координаты конца вектора (статус доступа `protected`, начало вектора в точке (0, 0)), конструктор, функция печати координат. Создать производный класс «вектор в трехмерном пространстве»: дополнительное поле — третья координата, конструктор, переопределенная функция печати (внутри вызывается функция базового класса). Создать по одному объекту каждого класса, показать вызов функций, продемонстрировать статический и динамический полиморфизм. Создать вектор указателей на объекты базового и производного классов и напечатать данные всех объектов.

**Решение.** Программа: [part2_inheritance.cpp](part2_inheritance.cpp). Конструктор производного класса явно вызывает конструктор базового (`vec3(...) : vec2(x, y)`), а переопределенная функция `print` сначала вызывает `vec2::print()`, затем печатает третью координату. Для двух вариантов полиморфизма сделано две пары классов:

- `vec2` и `vec3` — функции без `virtual` (статическое связывание): через указатель на `vec2`, настроенный на объект `vec3`, вызывается функция базового класса, поэтому координата `z` не печатается.
- `vec2v` и `vec3v` — функция `print` с `virtual` в базовом классе (динамическое связывание): вызывается функция того класса, к которому относится объект. С этими классами создан вектор указателей. В базовом классе добавлен виртуальный деструктор, чтобы объекты производного класса корректно удалялись через указатель на базовый класс.

**Результат работы программы:**

```
1. Static polymorphism (no virtual)
a.print():   x=3 y=4
b.print():   x=1 y=2 z=3
p->print():  x=3 y=4
p->print():  x=1 y=2  <- z is not printed: function chosen by pointer type

2. Dynamic polymorphism (virtual)
pv->print(): x=3 y=4
pv->print(): x=1 y=2 z=3  <- z is printed: function chosen by object type

3. Vector of pointers to objects of base and derived classes
1) x=3 y=4
2) x=1 y=2 z=3
3) x=-5 y=12
4) x=2 y=-1 z=0.5
```

**Проверка.** Объекты создаются с координатами (3; 4), (1; 2; 3), (−5; 12), (2; −1; 0,5), и именно эти значения напечатаны в порядке добавления в вектор. При статическом связывании для объекта `b` через указатель `p` печатаются только `x` и `y`, при динамическом — все три координаты.

## Выводы

- Перегрузка операций позволяет работать с объектами класса так же, как со стандартными типами. Операции `[]` и `=` обязаны быть членами класса, `<<` и `>>` определяются вне класса как дружественные функции, а операция вектор·число может быть и членом класса, потому что ее первый операнд — объект класса.
- Конструктор и присваивание с перемещением не копируют данные, а передают владение массивом, поэтому они быстрее копирования, а исходный объект остается пустым.
- При статическом связывании функция выбирается по типу указателя, при динамическом (с `virtual`) — по типу объекта, на который он указывает. Именно динамическое связывание позволяет обрабатывать объекты разных классов через один вектор указателей на базовый класс.
