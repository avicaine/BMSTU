## 1. ЧАСТЬ 1. КЛАССЫ И ПЕРЕГРУЗКА ОПЕРАЦИЙ

### 1.1. Цель работы

Овладение навыками разработки программ на языке Си++, использующих классы и перегрузку стандартных операций.

### 1.2. Условие задачи

Дан класс `Vector` — вектор из `double` (динамический массив и число элементов) с конструкторами (без параметров, на основе обычного массива, копирования, перемещения) и деструктором. Нужно перегрузить операции `[]`, `=` (с копированием и с перемещением), `<<`, `>>` и индивидуальную операцию варианта 8: **`*` — умножение вектора на число** (результат — вектор той же размерности, каждый элемент которого умножен на число). Показать разницу между копированием и перемещением. Класс разместить в заголовочном файле и файле реализации. Данные читаются из `input.txt`, результаты выводятся в `output.txt`.

### 1.3. Решение

Класс `Vector` хранит указатель `p` на динамический массив и число элементов `n`. Описание класса находится в `vector.h`, реализация — в `vector.cpp`, демонстрация — в `main.cpp`. Во всех конструкторах, деструкторе и операциях присваивания на консоль выводится сообщение, чтобы было видно, какая функция вызвалась.

Перегруженные операции (из `vector.h`):

```cpp
double &operator[](int index);
Vector &operator=(const Vector &v2);      // присваивание с копированием
Vector &operator=(Vector &&v2) noexcept;  // присваивание с перемещением
Vector operator*(double x) const;         // вектор * число
friend std::ostream &operator<<(std::ostream &os, const Vector &V);
friend std::istream &operator>>(std::istream &is, Vector &V);
```

Индивидуальная операция (из `vector.cpp`):

```cpp
Vector Vector::operator*(double x) const
{
    Vector R(n); // вектор-результат такой же размерности
    for (int i = 0; i < n; i++) R.p[i] = p[i] * x;
    return R;
}
```

**Способ перегрузки:**

* `[]` и `=` обязаны быть функциями класса. `[]` возвращает `double&`, чтобы элемент можно было и читать, и менять.
* `*` — первый операнд объект класса, поэтому это функция класса с одним параметром (число); она `const`, так как исходный вектор не меняется.
* `<<` и `>>` — первый операнд поток, а не `Vector`, поэтому они определены вне класса и объявлены дружественными (`friend`) для доступа к `p` и `n`.

**Копирование и перемещение.** Копирование создает новый массив и копирует в него элементы, исходный вектор не меняется. Перемещение забирает массив у исходного вектора, и тот становится пустым (`n = 0`).

### 1.4. Контрольный пример и результаты работы программы

## 2. ЧАСТЬ 2. НАСЛЕДОВАНИЕ КЛАССОВ

### 2.1. Цель работы

Овладение навыками разработки программ на языке Си++, использующих возможности наследования классов.

### 2.2. Условие задачи

Создать базовый класс «вектор на плоскости» (координаты конца вектора, статус доступа `protected`; конструктор; функция печати координат) и производный класс «вектор в трехмерном пространстве» (дополнительная координата; конструктор; переопределенная функция печати, внутри которой вызывается функция базового класса). Создать по одному объекту каждого класса, показать статический и динамический полиморфизм. Создать вектор указателей на объекты базового и производного классов и напечатать данные всех объектов.

### 2.3. Решение

Для двух вариантов полиморфизма сделано две пары классов: `vec2` и `vec3` без `virtual` (статический полиморфизм, функция выбирается по типу указателя) и `vec2v` и `vec3v` с `virtual` (динамический полиморфизм, функция выбирается по типу объекта). Вторая пара (из `part2_inheritance.cpp`):

```cpp
class vec2v // базовый класс
{
protected:
    double x, y; // координаты
public:
    vec2v(double x, double y) { this->x = x; this->y = y; }
    virtual void print() { cout << "x=" << x << " y=" << y; }
};

class vec3v : public vec2v // производный класс
{
    double z; // дополнительная координата
public:
    vec3v(double x, double y, double z) : vec2v(x, y) { this->z = z; }
    void print() { vec2v::print(); cout << " z=" << z; } // сначала функция базового класса
};
```

### 2.4. Контрольный пример и результаты работы программы

Ожидаемый результат (вручную): для объектов $(3;\ 4)$ и $(1;\ 2;\ 3)$ без `virtual` через указатель на базовый класс для второго объекта будет напечатано `x=1 y=2`, с `virtual` — `x=1 y=2 z=3`. Вектор указателей содержит $(3;\ 4)$, $(1;\ 2;\ 3)$, $(-5;\ 12)$, $(2;\ -1;\ 0.5)$ в порядке добавления, поэтому будут напечатаны четыре строки с этими значениями.

**Результат работы программы:**

```text
1. Static polymorphism (no virtual)
a.print():   x=3 y=4
b.print():   x=1 y=2 z=3
p->print():  x=3 y=4
p->print():  x=1 y=2  <- z is not printed: function chosen by pointer type

2. Dynamic polymorphism (virtual)
pv->print(): x=3 y=4
pv->print(): x=1 y=2 z=3  <- z is printed: function chosen by object type

3. Vector of pointers to objects of base and derived classes
1) x=3 y=4
2) x=1 y=2 z=3
3) x=-5 y=12
4) x=2 y=-1 z=0.5
```

**Вывод по части 2:**
Результат совпал с ожидаемым. Без `virtual` функция выбирается по типу указателя (координата `z` не напечатана), с `virtual` — по типу объекта. Динамическое связывание позволило напечатать в одном цикле объекты разных классов через вектор указателей на базовый класс.
